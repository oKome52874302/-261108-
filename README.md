# ファイブボンバー（軽音部レク用）

ネプリーグ「ファイブボンバー」風のゲームを、PC＋プロジェクターで遊ぶための Web アプリ。
正誤判定は人（司会・判定役）が行い、キーボードで入力する。

## 使い方

1. `index.html` をブラウザ（Chrome 推奨）で開く。インストール・ネット接続は不要
2. チーム名・制限時間・目標正解数を設定して「ゲーム開始」
3. ブラウザを全画面（`F11`）にしてプロジェクターに映す

## 操作（判定役）

| キー | 動作 |
| --- | --- |
| `Space` | お題オープン＆タイマー開始 / 一時停止 / 再開 |
| `Enter` | 正解（入力欄に回答を打っていればその文字を枠に表示、空なら「○」） |
| `X` | 不正解（ブザー） |
| `Backspace` | 直前の正解を取り消し（判定ミス用） |
| `N` | 結果確定して次のチームへ |
| `S` | スコア表示 / 戻る |

※ 入力欄に文字があるときは文字入力が優先され、`Enter` 以外のショートカットは効かない。

## ルール（初期値）

- 制限時間 30 秒、5 個正解でクリア
- 得点 = 正解数 ＋ クリアボーナス 3 点（「次へ」を押した時点で確定）
- チームは 1 問ごとに交代

## お題の追加

`data/questions.js` に追記する。

```js
{ theme: "お題", examples: ["回答例1", "回答例2"] },
```

`examples` は判定役の参考。ラウンド終了後に画面に表示される。

## 構成

```
index.html        画面
css/style.css     見た目（プロジェクター向けに大きめ）
js/app.js         ゲーム進行・キー操作
js/sound.js       効果音（Web Audio API で生成、音声ファイル不要）
data/questions.js お題データ
```
