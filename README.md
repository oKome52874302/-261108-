# ファイブボンバー（軽音部レク用）

ネプリーグ「ファイブボンバー」風のゲームを、PC＋プロジェクターで遊ぶための Web アプリ。
正誤判定は人（司会・判定役）が行い、キーボードで入力する。

## 使い方

1. GitHub Pages（https://okome52874302.github.io/-261108-/ ）を開く。または `index.html` をブラウザ（Chrome 推奨）で直接開く（ネット接続不要）
2. 設定画面でチーム・プレイヤー・お題・ルールを入力して「ゲーム開始」
3. ブラウザを全画面（`F11`）にしてプロジェクターに映す

## 操作（判定役）

| キー | 動作 |
| --- | --- |
| `Space` | お題オープン＆タイマー開始 / 一時停止 / 再開 |
| `Enter` | 正解（入力欄に回答を打っていればその文字を枠に表示、空なら「○」） |
| `X` | 不正解（ブザー）。枠は進まず、同じ人が考え直す |
| `Shift+Enter` | 入力欄の回答を不正解として枠に「✕回答」と残す |
| `Backspace` | 直前の判定（正解・不正解）を取り消し |
| `N` | 結果確定して次のチームへ |
| `S` | スコア表示 / 戻る |

※ 入力欄に文字があるときは文字入力が優先され、`Enter` 以外のショートカットは効かない。

## ルール（初期値）

- 制限時間 30 秒、5 個正解でクリア
- 得点 = 正解数 × 10 点（＋任意のクリアボーナス、初期値 0）。「次へ」を押した時点で確定
- 時間切れで爆弾が爆発
- チームは 1 問ごとに交代
- 不正解のときは同じ人が考え直す（正解するまで次の人に回らない）

## デザイン

番組の雰囲気に寄せたオリジナルデザイン（番組のロゴ・映像素材は使っていない）。
フォントは Google Fonts の Dela Gothic One / M PLUS 1p。オフラインで開いた場合は PC 標準のゴシック体で表示される。

## 音

効果音・BGM はすべてブラウザ内で合成したオリジナル音源（音声ファイルなし）。
回答中は BGM が流れ、残り 5 秒でテンポが上がる。音量と BGM の有無は設定画面で変更できる。

## チーム・プレイヤー・お題の準備

すべて設定画面で編集できる。入力内容はブラウザに自動保存される。

- **チーム**：「＋ チームを追加」で増やし、× で削除
- **プレイヤー**：1行に1人。この順に回答し、次のラウンドは続きの人から始まる（時間切れで詰まった人は回答済み扱い）。空欄でも遊べる
- **お題**：1行に1問、`お題 | 回答例、回答例` の形式。回答例は判定役の参考で、ラウンド終了後に表示される

```
海に面していない都道府県 | 栃木、群馬、埼玉、山梨、長野
軽音部の部員の名前
```

別のPCで使うときは「ファイルに書き出し」で JSON を保存し、本番PCで「ファイルから読み込み」する。
「初期データに戻す」を押すと `data/questions.js` のサンプルお題に戻る。

## 構成

```
index.html        画面
css/style.css     見た目（プロジェクター向けに大きめ）
js/app.js         ゲーム進行・キー操作
js/setup.js       設定画面（チーム・プレイヤー・お題の編集、保存、読み書き）
js/sound.js       効果音・BGM（Web Audio API で生成、音声ファイル不要）
data/questions.js 初期お題データ
```
