# ファイブボンバー（軽音部レク用）

ネプリーグ「ファイブボンバー」風のゲームを、PC＋プロジェクターで遊ぶための Web アプリ。
正誤判定は人（司会・判定役）が行い、キーボードで入力する。

## 使い方

1. GitHub Pages（https://okome52874302.github.io/-261108-/ ）を開く。または `index.html` をブラウザ（Chrome 推奨）で直接開く（ネット接続不要）
2. 設定画面でチーム・プレイヤー・お題・ルールを入力して「ゲーム開始」
3. ブラウザを全画面（`F11`）にしてプロジェクターに映す

## 操作（判定役）

答えは入力せず、司会・判定役が正誤だけをキーで決める。

| キー | 動作 |
| --- | --- |
| `Space` | お題オープン＆タイマー開始。回答中は**押している間だけ一時停止**し、離すと再開 |
| `↑` | 正解（一時停止中でも判定できる） |
| `↓` | 不正解。枠は進まず、同じ人が考え直す |
| `Backspace` | 直前の判定を取り消し |
| `→` | 結果確定して次のチームへ |
| `Tab` | スコア表示 / 戻る |
| `Esc` | 設定画面に戻る（ゲームは一時停止、続きから再開できる） |

画面下のボタンをクリックしても同じ操作ができる（Space のボタンは一時停止／再開の切り替え）。

## ルール（初期値）

- 制限時間 30 秒、5 個正解でクリア
- 得点 = 正解数 × 10 点（＋任意のクリアボーナス、初期値 0）。「次へ」を押した時点で確定
- 時間切れで爆弾が爆発
- チームは 1 問ごとに交代
- 不正解のときは同じ人が考え直す（正解するまで次の人に回らない）
- 判定に迷ったときは Space を押したままにすればタイマーが止まる

## デザイン

番組の雰囲気に寄せたオリジナルデザイン（番組のロゴ・映像素材は使っていない）。
フォントは Google Fonts の Dela Gothic One / M PLUS 1p。オフラインで開いた場合は PC 標準のゴシック体で表示される。

## 音

効果音・BGM はすべてブラウザ内で合成したオリジナル音源（音声ファイルなし）。
回答中は BGM が流れ、残り 5 秒でテンポが上がる。音量と BGM の有無は設定画面で変更できる。

## 勝敗の決め方

設定画面の「勝敗の決め方」で決める。1ターン ＝ 全チームが1問ずつ答えること。

- **ターン数**：そのターン数を終えたら終了し、最高得点のチームが優勝（同点なら引き分け）
- **目標点**：先に到達したチームの勝ち。「そのターンは最後まで行う」をオンにすると、到達したターンの残りのチームも答えてから決着する（後攻にもチャンス）
- どちらも 0 なら終わりなし。両方設定した場合は先に満たした方で終了

ゲーム中は `Esc` か「⚙ 設定に戻る」で設定画面に戻れる。ターン数・目標点・制限時間などを変えて「ゲームに戻る（続きから）」で、スコアをそのままに再開できる。
勝敗が決まると優勝画面になり、「このまま続ける」か、設定に戻って延長できる。
チーム数の変更は「ゲーム開始」で新しいゲームを始めたときに反映される。

## シックスボンバー（人数の変更）

設定画面の「目標正解数」が 1 問で答える人数＝枠の数になる。「シックス（6）」ボタンで 6 枠のシックスボンバーになり、
タイトルやゲーム画面の表記も「SIX BOMBER」に変わる。1〜12 枠まで設定でき、7 枠以上は 2 段で表示される。

## ハイパーボンバー（往復）

「ハイパー（5人往復・60秒）」ボタンで、本家ネプリーグのハイパーボンバー形式になる。
1→5 と答えたら 5→1 と折り返し、10 個正解でクリア。5 人目は折り返しで 2 回続けて答える。
回答パネルは 2 段で、下の段は右から左に並ぶ（同じ人の枠が縦にそろう）。
「往復する」のチェックで、人数を変えた往復（例：6人往復で12個）にもできる。答えが 10 個以上あるお題を用意すること。

## チーム・プレイヤー・お題の準備

すべて設定画面で編集できる。入力内容はブラウザに自動保存される。

- **チーム**：「＋ チームを追加」で増やし、× で削除
- **プレイヤー**：1行に1人。この順に回答し、次のラウンドは続きの人から始まる（時間切れで詰まった人は回答済み扱い）。空欄でも遊べる
- **お題**：1行に1問。左に「お題」、右に「答えの例」を「、」区切りで書く（空欄でもよい）。答えの例はラウンド終了後に表示され、判定の参考になる
  - 「まとめて追加」に、スプレッドシートの2列（お題・答えの例）をそのまま貼り付けられる

別のPCで使うときは「ファイルに書き出し」で JSON を保存し、本番PCで「ファイルから読み込み」する。
「初期データに戻す」を押すと `data/questions.js` のサンプルお題に戻る。

### 音が出ないとき

- 設定画面の「🔊 音を確認」で、会場のスピーカーから音が出るか事前に確かめる
- ブラウザが再生を止めても、キーを押すかクリックすると自動で再開する
- スピーカーやプロジェクターを付け外ししたときは、出力先を自動で切り替える
- それでも出ないときは、PC の音量・出力先（HDMI など）、ブラウザのタブのミュートを確認する

## 構成

```
index.html        画面
css/style.css     見た目（プロジェクター向けに大きめ）
js/app.js         ゲーム進行・キー操作
js/setup.js       設定画面（チーム・プレイヤー・お題の編集、保存、読み書き）
js/sound.js       効果音・BGM（Web Audio API で生成、音声ファイル不要）
data/questions.js 初期お題データ
```
